# qa-test-triage

修复前先复现指定失败。使用 trace、截图、请求状态、页面树区分环境故障、产品缺陷、数据污染与定位失效。
只有证据表明测试实现过期时才修改定位或等待方式；保留业务断言与用例 ID，不使用 skip/xfail/retries 掩盖缺陷。
最多两轮修复加重跑，仍失败则保留失败并报告阻塞。不能仅凭模型判断宣布通过。
结束时列出复现命令、退出状态、改动文件与尚未验证项。截图和页面树可能含敏感数据，输出前脱敏。

# 待办功能测试计划

环境：本地 demo；每个用例独立 tenant；无需登录。

| ID | 场景 | 步骤 | 预期 |
|---|---|---|---|
| API-001 | 任务生命周期 | POST → GET → PATCH → GET | 201/200，契约正确，完成状态持久化 |
| API-002 | 标题边界 | 空白/101字符/非字符串 | 422，数据不写入 |
| API-003 | 不存在任务 | PATCH 随机 UUID | 404 |
| API-004 | 租户隔离 | A 创建、B 查询 | B 返回空列表 |
| API-005 | 状态类型 | completed 传字符串 | 422，原状态不变 |
| API-006 | 租户必填 | GET 不带租户 | 400 |
| UI-001 | 创建并完成 | 添加→勾选→刷新 | 任务仍完成 |
| UI-002 | 跨层验证 | API 创建→UI 刷新 | 页面显示任务 |
| UI-003 | 服务异常 | POST 返回503 | 显示错误，列表不新增 |

API-002 由 5 个数据驱动用例覆盖。增加场景应记录前置条件、清理方式及风险。
